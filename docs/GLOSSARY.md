# Glossary

One name per thing. Buttons, menus, titles, tooltips, errors and VoiceOver labels use these words only.

| Term | Means | Not |
| --- | --- | --- |
| AM2R 1.1 | The player's own copy of the original game (`AM2R_11.zip` or its folder); the only source of game files | original game, base game, source, ROM |
| Community Updates | The fan-maintained AM2R releases (1.5.5 today) that the app installs on top of AM2R 1.1 | patch, mod, update pack |
| Patch data | The files downloaded from GitHub that turn AM2R 1.1 into Community Updates | PatchData, autopatcher, xdelta |
| Profile | One installed, playable game (e.g. "Community Updates 1.5.5") with its own saves and settings | install, instance, build, game folder |
| Install | Make a profile: download patch data, patch AM2R 1.1, put the files in place | build, patch, set up |
| Update | Re-install a profile with newer patch data, keeping saves and settings | upgrade, re-patch |
| Play | Start the game for the selected profile | Launch, Run, Start |
| Stop | End a running game from the launcher | Kill, Force Quit, Terminate |
| Engine | What runs the game: Native (Butterscotch, Apple silicon) or Rosetta (official runner) | runner, backend, interpreter |
| Native | The bundled Butterscotch engine running on Apple silicon | arm64, Butterscotch (in UI copy) |
| Rosetta | The official GameMaker runner translated by Rosetta 2 | Intel, x86, legacy |
| Log | Text the game wrote while it ran | console, output, stdout |
| Saves | The profile's save slots and its `config.ini` | save data, save files |
| Data folder | Where profiles, patch data and logs live | library, storage, app support |
| Layout | Which controller buttons open the map and the pause menu: Mac, Original, or Custom | preset, mapping, binding |
| Game settings | Display, controller and language of one profile, kept in its config.ini (on the Play page) | options, preferences |
