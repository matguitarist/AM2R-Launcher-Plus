## The same Help menu as every app

- **What's New in AM2R Launcher Plus** opens the latest release notes.
- **Report a Problem…** opens a new GitHub issue with the app version, build and macOS version already filled in.
- **Check for Updates…** is always in the AM2R Launcher Plus menu, greyed out when updates aren't available.
- The launcher's log is **Help › Show Log** (⌥⌘L); the game's log is **Game › Show Game Log** (⌘L).
